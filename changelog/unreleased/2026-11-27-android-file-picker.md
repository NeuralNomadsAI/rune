- Android: `Tx::open_file` and `Tx::open_files` show the system's document picker. It answers with `content://` URIs, so each picked document is copied into the app's cache and the copies' paths answer the dialog, until the app's process next starts. `Tx::save_file` and `Tx::open_folder` are refused with an error. An embedding host that shows file dialogs itself keeps them from being refused (`host.file_dialogs`).
