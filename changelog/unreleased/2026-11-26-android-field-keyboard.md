- Android: the keyboard a field needs. A secret field (`El::secure`) raised no keyboard and took none of its text, so a password could only be typed on a hardware keyboard: it now gets the keyboard as a password's (no correction, suggestion or learning) and takes what it types. A one-line field has an action key, which submits as Return does, where a longer one keeps Return, and the keyboard is restarted when focus goes from one kind of field to another. `examples/android-fields` (`scripts/android-run.sh --app fields`) shows a field of each kind.
