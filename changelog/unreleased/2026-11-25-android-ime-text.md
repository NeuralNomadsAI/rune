- Android: the input method now reads and edits the text around the caret. `getTextBeforeCursor`, `getTextAfterCursor`, `getSelectedText` and `getExtractedText` return the caret's paragraph in UTF-16 offsets (emoji never split), the selection is reported with `updateSelection` and the input method restarts when the caret changes paragraph, `setComposingRegion` takes committed text back into a composition (autocorrect, reconversion), and `deleteSurroundingText` deletes by range instead of by key. `commitContent` pastes a keyboard's image (a sticker, a GIF's first frame) as PNG, decoded off the UI thread.
