- `El::input_mode(InputMode)` (and rune-kit's `TextInput::input_mode`) says what a text field holds, for a touch keyboard to lay itself out by, with HTML's `inputmode` values: `Text` (the default), `Email`, `Url`, `Numeric`, `Decimal`, `Tel`, `Search` or `None`. Android's keyboard shows the keys for it, a `secure` number gets a PIN's, `Search` a search key, and `None` raises no keyboard; other hosts ignore it. It refuses no text: a pasted letter still goes into a number field.
